# Legatum International School — Landing Page

Landing page de Admissões 2027, Goiânia. Educação Clássica como metodologia, cosmovisão cristã como fundamento.

🔗 **Site publicado:** ver link do GitHub Pages nas configurações do repositório.

## Estrutura

- `index.html` — página completa (17 seções, self-contained: CSS e JS inline)
- `assets/` — brasão e lockups do logotipo oficiais (extraídos do manual de identidade)

## Stack

HTML/CSS/JS puro, sem build step. Fontes: Cinzel (display) + Cardo (corpo), via Google Fonts.
